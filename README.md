## Comandos 
### Venv
1. **Criar venv** 
        &rarr; `python -m venv venv` 

    
2. **Entrar no venv**
    * Windows&nbsp; 
        &rarr; `.\venv\Scripts\Activate.ps1`
    * Linux&emsp;&emsp; 
        &rarr; `source venv/bin/activate`
    
3. **Instalar dependências**:
    &rarr; `pip install -r requirements.txt`
